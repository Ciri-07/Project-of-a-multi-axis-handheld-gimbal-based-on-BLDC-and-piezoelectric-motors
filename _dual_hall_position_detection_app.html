1. 双线性 Hall 角度检测模型

两只线性 Hall 固定在电机端面附近，理想情况下空间夹角为 90°。转子磁场扫过传感器时，两路输出形成近似正余弦信号，经过归一化后可通过 atan2 解算磁场角，再换算为机械角。

θmag = p · θm + θ0
Hs = Os + As sin(θmag) + ns
Hc = Oc + Ac cos(θmag + Δφ) + nc

其中 p 是 Hall 磁极对数，O 是零偏，A 是幅值，Δφ 包含安装夹角偏离 90°和额外相位误差。

2. 误差来源

真实系统中，两路 Hall 不会天然构成标准单位圆，常见误差会把 Lissajous 相图从圆变成偏心圆、椭圆、倾斜椭圆或带波纹的闭合曲线。

  • 零偏误差：圆心偏离原点。
  • 幅值不一致：圆被拉伸成椭圆。
  • 安装角不为 90°：相图倾斜，解角产生周期误差。
  • 磁钢偏心/充磁不均：出现 2、3、5、6 次等高次谐波。
  • ADC 量化与白噪声：带来随机解角抖动。

3. 确定性补偿链路

确定性补偿先处理可标定、可重复的误差：零偏、幅值、相位和谐波。其目标是把两路信号重新拉回标准正余弦关系。

xs = (Hs - Os) / As,   xc = (Hc - Oc) / Ac
xc,corr = (xc + xs sinΔφ) / cosΔφ
efit(θ)=Σ[Aksin(kθ)+Bkcos(kθ)]

补偿后再用 atan2 输出角度：θ̂ = atan2(xs, xc,corr)。

4. 动态估计与滤波

LPF、α-β 和 ESO 面向随机噪声、采样误差和动态扰动。LPF简单但有滞后；α-β用“角度-速度”预测提高动态跟随；ESO进一步估计未建模扰动。

LPF:   y[k] = α y[k-1] + (1-α)x[k]
α-β:   θ-=θ̂[k-1]+Tsω̂[k-1],   e=θmeas-θ-
ESO:   z1≈θ,   z2≈ω,   z3≈d

所以本软件把确定性补偿和动态估计分开展示，方便判断误差到底来自结构、磁场还是采样噪声。

1
两路 Hall
采集 Hs/Hc。模型：H=O+A·sin/cos(θ)+谐波+噪声。
2
零偏与幅值归一化
x=(H-O)/A，把偏心圆和幅值椭圆先拉回单位尺度。
3
相位 / 安装角补偿
用 xc,corr=(xc+xssinΔφ)/cosΔφ 修正非 90°安装。
4
谐波重构补偿
用 Σ(Ak sin kθ + Bk cos kθ) 拟合周期误差并扣除。
5
atan2 解角
θ̂mag=atan2(xs,xc)，机械角 θ̂m=θ̂mag/p。
6
α-β / ESO 动态估计
α-β估计角度速度，ESO进一步估计扰动 z3≈d。

软件功能模块

本软件包括参数配置、信号生成、误差注入、补偿算法、工况仿真、结果显示和报告导出七个模块。

当前模型支持零偏、幅值不一致、相位不正交、2/3/5/6 次谐波、ADC 量化、白噪声、恒速、变速、冲击和负载扰动等工况。

补偿链路采用零偏估计、幅值归一化、相位补偿、谐波重构、角度域傅里叶误差补偿、α-β 状态估计和离散 ESO 估计。
