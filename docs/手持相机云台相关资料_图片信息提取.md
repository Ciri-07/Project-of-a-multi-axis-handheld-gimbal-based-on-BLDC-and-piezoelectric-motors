### 2.3 电机验收规格与传感器相关指标

图片 03-05 给出了电机/云台检测与控制的验收指标。与传感器方向最相关的是检测精度、滞后精度、跟随精度和稳像精度。

| 指标类别 | 图片中可识别指标 | 对传感器方案的含义 |
|---|---|---|
| 检测角度 | 检测精度约为 ≤±0.005° @1σ，图片中标注 IMU | IMU/位置传感器必须支持极高角度分辨率和低噪声姿态估计 |
| 线性度 | 标定后线性误差 ≤1% | 需要做传感器标定、安装矩阵标定、编码器零位标定 |
| 滞后精度 | 位置误差约为 ≤±0.005° @1σ | 传感器链路延迟必须小，滤波不能过重 |
| 跟随精度场景1 | 0.4G冲击扰动下控制误差约 ≤±0.005° @1σ | 对应走路或轻扰动工况，需验证抗扰和姿态估计稳定性 |
| 跟随精度场景2 | 1.6G冲击扰动下控制误差约 ≤1% | 对应跑动或强扰动工况，需要自适应滤波、扰动观测、控制限幅 |
| 稳像精度场景1 | 0.4G冲击扰动下，稳像精度约 ≤1.3 pixel，曝光约1s，拍摄距离约1m | 控制指标最终应映射到成像质量，而不是只看电机角度 |
| 稳像精度场景2 | 1.6G冲击扰动下，稳像精度约 ≤3 pixel，曝光约33ms，拍摄距离约1m | 强扰动下应关注图像稳定误差和动态残余振动 |

注意：图片来自屏幕拍照，部分数值存在模糊。上述指标适合用于方案中的“目标/参考指标”，正式承诺前应和甲方原始SOW文件核对。

### 2.4 验收/测试方法要点

图片 03-05 可识别到的测试方法包括：

| 测试方向 | 提取信息 |
|---|---|
| 样品数量 | 电机单体测试样品数量约 3 颗；多轴机构测试样品数量约 1 颗 |
| 位置点测试 | 电机行程分为 N-1 段，位置点 p1, p2 ... pN，N≥3，在各位置采集角度或控制误差 |
| 采样要求 | 可见 5k 采样率、采集 10s/6s/20s 等描述 |
| 正弦运动 | 使用 sin 波作为电机命令，频率和角度如 2Hz ±1°、4Hz ±1°、0.5Hz ±90°、1Hz ±45° 等 |
| 冲击扰动 | 使用 0.4G、1.6G 冲击扰动波形作为振动台输入 |
| 三轴组合 | Pitch/Roll/Yaw 轴分别或组合输入复合波形 A、复合波形 B |
| 成像测试 | 固定距离约 1m，按曝光时间拍照，统计模糊像素宽度或稳定误差 |

这些信息说明传感器方案不能只做静态精度，需要覆盖动态扰动、冲击、三轴耦合和成像稳定效果。

## 3. 对当前可行性方案的补充建议

根据图片资料，建议在《手持相机云台高精度控制传感器融合可行性方案》中补充或强调以下内容：

| 补充点 | 建议写法 |
|---|---|
| 指标对齐 | 把 ≤±0.005°、0.4G/1.6G、1.3 pixel/3 pixel 等写为“来自SOW图片资料的参考验收指标，正式数值需以甲方原始文件为准” |
| IMU地位 | 明确 IMU 是大角度级联系统绝对姿态基准之一，不只是滤波辅助传感器 |
| 加速度扰动处理 | 0.4G/1.6G冲击下，必须使用自适应加速度权重，不能固定相信加速度计 |
| 三轴解耦 | 由于存在三级级联系统和大角度范围，姿态融合应使用四元数/旋转矩阵，不宜只用欧拉角 |
| 成像闭环指标 | 传感器融合输出不只看角度误差，也要服务于最终图像像素稳定误差 |
| 测试数据接口 | 仿真与实验应输出 pitch/yaw/roll、IMU原始数据、编码器角、控制误差、成像误差 |

## 4. 可直接写进方案的依据性表述

可在可行性方案中使用以下表述：

```text
根据现有SOW图片资料，项目验收不仅关注电机角度检测精度，还关注0.4G/1.6G冲击扰动下的跟随精度和成像稳像精度。因此，传感器方案需要同时满足低漂移、低延迟、抗冲击扰动和三轴大角度解耦需求。
```

```text
现有技术交流材料中明确提出三级级联系统、三级间耦合及大角度运动范围，且将IMU作为绝对位置基准。因此，本方案建议采用四元数姿态融合、编码器轴角融合和安装矩阵标定，而不采用单轴欧拉角滤波作为最终方案。
```

```text
0.4G和1.6G冲击扰动说明加速度计在动态过程中会受到明显线加速度污染。互补滤波算法必须具备自适应加速度权重，静止或准静态时利用加速度修正漂移，强动态时降低加速度权重，主要依靠陀螺和编码器维持短时姿态稳定。
```
